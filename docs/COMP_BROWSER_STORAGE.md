# COMP ZIP을 이 PC의 브라우저에 보관

사이드바 맨 위 **COMP 데이터 · 이 브라우저에 보관**에서 ZIP을 선택합니다. 앱이 ZIP 구조와 자료를 검증하면 **보관됨**이라는 표시가 나타납니다. 같은 웹사이트를 같은 PC·브라우저·프로필에서 다시 열면 보관한 ZIP을 자동으로 불러옵니다. 새 ZIP을 선택하면 기존 보관 파일 하나를 교체합니다. 매일 새로 업로드할 필요는 없습니다.

보관은 브라우저의 IndexedDB를 사용합니다. MYBOX나 공유 서버 파일 저장은 사용하지 않습니다. 백테스트 계산을 위해 현재 접속의 앱 서버로 ZIP을 전송하는 것은 기존 업로드와 같습니다. 서버 디스크에 ZIP을 영구 저장하거나 다른 사용자의 데이터로 등록하지 않습니다.

다른 PC·브라우저·프로필·웹사이트 주소에서는 다시 선택해야 합니다. 브라우저 저장 데이터 삭제, 시크릿 모드 종료, 저장 공간 정리로 파일이 없어질 수 있습니다. 브라우저 저장이 차단되거나 용량 부족으로 실패하면 화면에 실패 표시를 보여줍니다. 이 경우 **일회용 업로드 · 브라우저 보관 안 함**을 사용할 수 있습니다.

**브라우저 보관 지우기**는 이 앱의 보관 ZIP만 지웁니다. PC의 원본 파일은 그대로입니다. 잘못된 ZIP을 선택해도 검증을 통과하기 전에는 기존 보관 파일을 교체하지 않습니다. 업종 CSV는 이번 보관 대상에 포함하지 않습니다.

최대 ZIP 크기는100MB이며, 기존 파일 이름은 `COMP_FScore_Market_20200102_20261008.zip`입니다. 사용자 데이터나 보관 파일은 GitHub에 올리지 않습니다.
