# KOSPI200 회계 수정 — 2026-09-13

일반형과 공격형의 활성 백테스트 및 민감도 계산을 `core/kospi_accounting.py`로 연결했다.

- 목표비중이 바뀔 때만 주문한다. 변경이 없으면 보유 단위와 현금을 유지하고 실제 비중은 가격에 따라 변한다.
- 신호 확정 종가에서 수수료를 고려해 주문 수량을 결정한다. 다음 시가를 미리 보고 수량을 결정하지 않는다.
- 시간외 부분체결은 매도/매수 예정 수량 각각에 사용자가 선택한 체결률을 적용한다. 잔량은 다음 시가에 체결한다.
- 다음 시가 갭은 기존 보유 수량에 먼저 반영한다. 잔량 매수 시 현금이 부족하면 매수 수량을 줄이고 `Unfilled Value`에 기록한다. 이 미체결분은 이후 자동 재주문하지 않는다.
- 체결비용은 실제 매수금액+매도금액에 편도 비용률을 곱한다. 최초 진입에도 부과한다.
- 결과 비중은 종가 평가 및 시간외 체결 후 실제 비중이다. 목표비중과 다를 수 있다.
- 시간외 체결률과 신호 산식은 변경하지 않았다.

추가 실전 안전장치:

- KODEX 200과 KODEX 레버리지의 거래일이 같고 시가·종가가 양수인지 확인한다. 누락 시세를 0% 수익률로 바꾸지 않고 실행을 중단한다.
- Yahoo 대체 데이터에서 `Close`와 `Adj Close`가 함께 있을 때 원시 `Close`를 체결가격으로 명확히 선택한다.
- 100% 목표비중도 주문 수수료를 낼 현금이 남도록 주문 수량을 줄인다.
- 텔레그램의 시간외 종가 가능 시간은 15:40부터로 판단하며, 기본 스케줄 시각은 15:45로 변경했다.

이 엔진은 기존 overnight/intraday 수익률로 정규화 가격을 복원한 분수 단위 회계다. 보유 유지와 손익·비용 연결은 검증했지만 거래소 원가격 정수주, 분배금 현금 지급일, 실제 주문 체결 기록까지 재현한 엔진은 아니다. 다음 시가 주문에서 예상 종가와 시가가 다르면 목표비중과 실제 체결 비중이 달라진다.
