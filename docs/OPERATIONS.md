# Operations Checklist

실전 적용 전에는 아래 체크리스트를 전략별로 통과시킵니다.

## 1. 데이터

- 가격 데이터 시작일과 종료일이 의도한 기간과 맞는지 확인합니다.
- 결측치, 0 가격, 비정상 수익률이 필터링되는지 확인합니다.
- 한국 전략은 KRX/pykrx/FinanceDataReader의 컬럼명 변경 가능성을 확인합니다.
- 미국 전략은 yfinance 티커 변경, 상장폐지, 다운로드 실패 종목을 따로 기록합니다.

## 2. 백테스트 가정

- 신호 생성일과 실제 진입일이 분리되어 있는지 확인합니다.
- 다음 시가, 다음 종가, 당일 종가 중 어떤 체결 가정을 쓰는지 명확히 합니다.
- 거래비용, 세금, 슬리피지, 환전 비용을 보수적으로 반영합니다.
- 리밸런싱 주기와 실제 주문 가능 날짜가 일치하는지 확인합니다.

## 3. 결과 검증

- CAGR, MDD, Sharpe, Calmar를 벤치마크와 비교합니다.
- 최근 1년, 3년, 5년 구간 성과를 따로 봅니다.
- 가장 큰 손실 구간의 보유 종목과 국면 판단을 확인합니다.
- 파라미터를 조금 바꿔도 결과가 크게 무너지지 않는지 확인합니다.

## 4. 실전 전 모의 운용

- 같은 조건으로 최소 3개월 이상 추천 종목을 기록합니다.
- 매 리밸런싱마다 추천 종목, 가격 기준일, 주문 예정일을 남깁니다.
- 결과 파일을 저장하고, 이전 결과와 달라진 이유를 메모합니다.
- 자동 주문 전에는 수동 승인 흐름으로 먼저 운용합니다.

## 5. 운영 중단 조건

- 데이터 소스가 바뀌어 결과가 재현되지 않을 때
- 리밸런싱 당일 주문 대상이 비정상적으로 바뀔 때
- 실현 MDD가 사전 허용치를 넘을 때
- 전략의 핵심 가정이 시장 구조 변화로 깨졌다고 판단될 때
