# QQQ/TQQQ 선택형 10일 음수 보정

QQQ TQQQ holdings 페이지 → 선택형 위험 보정 →
`QQQ 10일 수익률 음수 시 목표 위험 확대 금지`를 선택하고 Run backtest를 누릅니다.
기본값 OFF는 기존 전략입니다. 옵션 ON이면 백테스트와 다음 시가 주문 계산에 동일하게 적용됩니다.

전일 종가 기준 QQQ 10거래일 수익률이 음수이면 목표 위험(QQQ 비중 + 3×TQQQ 비중)을
직전 보정 목표 위험 이하로 제한합니다. 두 종목을 비례 축소하고 차액은 현금입니다.
위험 축소는 허용하며 10일 수익률이 0 이상이면 기존 목표를 다시 허용합니다.
Turnaround와 cash sweep을 포함한 최종 목표에 적용합니다.
실제 TQQQ 평가 비중 상한이나 모든 매수 금지는 아닙니다.

SOXX/SOXL의 검증된 함수를 종목명 변환으로 재사용하여 두 전략의 보정 규칙이 다르지 않도록 합니다.
주가 변화만으로 실제 보유 비중을 맞추지 않는 원칙은 유지합니다.
옵션은 각 페이지 세션에서 선택하며, 별도 Telegram 예약 실행에는 자동 적용되지 않습니다.
옵션 전환 시 현재 잔고와 미체결 여부를 확인해야 하며 자동 주문을 제출하지 않습니다.
과거 성과 및 이번 기능 추가는 향후 손실 감소를 보장하지 않습니다.
