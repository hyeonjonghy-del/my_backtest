# QQQ/TQQQ 실전 집행 회계 변경

QQQ/TQQQ Holdings 전략은 신호 계산과 실제 주문 회계를 분리한다.

- 추세·변동성 신호는 분할과 배당이 보정된 수정종가를 사용한다.
- 정수 주수, 계좌 평가, 주문 금액은 당시의 원주가를 사용한다.
- 주문 수량은 신호일 원종가로 확정하며 다음 정규장 시가에 그 수량을 체결한다. 시가 갭으로 현금이 부족하면 매수 주수를 줄인다.
- 주식 분할은 효력일 장 시작 전에 보유 주수에 반영한다.
- 배당은 배당락일 보유 권리를 기준으로 그날 거래 후 현금에 반영한다. Yahoo 일봉에는 실제 지급일이 없으므로 이는 총수익 회계를 위한 근사이며 당일 장 시작 주문에는 사용할 수 없다.
- 수수료는 매수와 매도 체결 금액 양쪽에 적용하며 주문표도 수수료 예산을 먼저 남긴다.
- 주간·월간 모드의 주문표는 다음 거래일이 실제 리밸런싱 회차일 때만 새 목표를 적용한다.
- 신호가 그대로여도 신규 계좌나 미체결·부분 체결이 있으면 `Recover missed/partial prior execution`을 켜서 현재 목표로 복구할 수 있다.
- Yahoo 일봉의 최신 완료 거래일에 종가와 수정종가만 비어 있을 때, Yahoo 메타데이터의 정규장 확정가격이 같은 날짜의 장 마감 후 가격이고 일봉 가격 범위 안에 있으며 분할 이벤트가 없다면 두 종가를 보완한다. 배당락일에는 배당 이벤트를 보존한다. 보완 사실을 화면에 표시하며 조건이 맞지 않으면 해당 일봉을 주문 신호에 사용하지 않는다.

비교 전략도 같은 전일 종가 확정·다음 시가 체결 순서와 같은 거래비용을 사용한다. 따라서 종가 수익률에 새 비중을 바로 곱하는 과거 비교 방식은 제거했다.
