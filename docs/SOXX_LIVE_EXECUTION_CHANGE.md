# SOXX/SOXL 실전 체결 수정 — 2026-09-13

`SOXX / SOXL Vol Target`과 비교용 `SOXX Vol Target`을 종가 신호 후 다음 정규장 시가에 실행할 수 있는 규칙으로 통일했다.

- 신호일 종가와 당시 자산가치로 주문 단위를 고정하고 다음 시가에 체결한다. 백테스트가 다음 시가를 미리 보고 목표 단위를 다시 계산하지 않는다.
- 수익률 계산은 분배금·분할을 포함하는 수정가격을 사용하지만 실제 계좌 평가와 주문 수량은 원시 종가를 사용한다.
- 매도금액과 매수금액을 각각 편도 회전율에 포함한다. SOXX 단독 전략의 `/ 2` 비용 축소를 제거했다.
- 수수료를 먼저 유보하므로 100% 목표비중 주문이 수수료 때문에 주문가능금액을 넘지 않는다.
- SOXX/SOXL의 Weekly/Monthly 선택은 NYSE 거래일 달력으로 다음 세션이 새 주·월인지 확인한 뒤에만 주문을 만든다.
- 새 계좌 또는 전날 미체결·부분체결은 `Recover missed/partial prior execution`으로 현재 목표에 다시 맞출 수 있다. 텔레그램에는 신호가 유지될 때 별도의 복구 수량을 표시한다.
- 미국 정규장이 끝나기 전에는 당일 일봉을 사용하지 않고, 알림 데이터가 최근 완료 NYSE 세션과 다르면 실행을 중단한다.
- SOXX/SOXL 최신 완료 일봉의 종가와 수정종가만 비어 있을 때 Yahoo 메타데이터의 같은 날짜 정규장 확정가격을 검증하여 보완한다. 배당락일은 배당 이벤트를 보존하며 보완할 수 있지만, 분할 이벤트가 있거나 날짜·가격 범위가 맞지 않으면 주문 신호의 신선도 검사를 유지한다.
- SOXX/SOXL·BIL 사이의 거래일 또는 시가·종가가 누락되면 0% 수익률이나 전일 가격으로 채우지 않고 중단한다.
- 고정혼합 비교선도 동일한 다음 시가·편도 비용 엔진으로 계산한다.

SOXL은 일간 3배 목표 상품이다. 장기간 기초지수 누적수익의 정확한 3배를 목표로 하지 않으며 복리와 변동성의 영향을 받는다. 이 코드는 실제 SOXL 수정가격을 사용하며 합성 3배 수익률로 대체하지 않는다.
