# SOXX/SOXL 선택형 10일 음수 보정

SOXX SOXL vol 페이지 사이드바 → 선택형 위험 보정 →
`SOXX 10일 수익률 음수 시 목표 위험 확대 금지`를 선택하고 Run backtest를 누릅니다.
기본값은 OFF로 기존 전략을 유지합니다.

전일 종가 기준 SOXX 10거래일 수익률이 음수이면, 오늘 목표 위험
`SOXX 목표 비중 + 3 × SOXL 목표 비중`을 직전 보정 목표 위험 이하로 제한합니다.
두 종목 비중을 비례 축소하고 차액은 현금으로 유지합니다.
기존 목표 위험이 줄면 그대로 허용하며, 10일 수익률이 0 이상이면 기존 목표를 다시 허용합니다.
Turnaround에도 적용합니다. SOXL 실제 평가 비중 상한이나 모든 매수 금지는 아닙니다.

백테스트에는 전일 신호를 사용하며 전체 워밍업 이력에서 순차 계산합니다.
다음 거래일 주문 계획에도 동일한 규칙을 적용합니다.
옵션 변경 후에는 이전 옵션으로 이미 주문했는지 및 현재 잔고를 확인해야 합니다.
자동 주문을 제출하지 않습니다.

사이드바 선택은 이 페이지에만 적용됩니다. 별도 Telegram 예약 실행 설정을 변경하지 않습니다.
로컬 소스 수정만으로 Streamlit Cloud나 GitHub 배포가 갱신되지는 않습니다.

검증: 기본 실행 관련 테스트 12개, 보정 테스트 3개 통과.
2012-01-03~2026-10-16의 3,719거래일 목표가 기존 NoIncrease_Mom10 연구 원장과 일치합니다.
과거 성과는 미래 하락 방어나 수익률을 보장하지 않습니다.
