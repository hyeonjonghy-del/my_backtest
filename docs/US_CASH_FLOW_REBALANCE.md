# SOXX/SOXL·QQQ/TQQQ 추가 입금 처리

두 페이지의 원본 및 10일 음수 옵션 모두 동일한 규칙입니다.

- 목표 비중이 바뀌면 전체 계좌를 현재 목표 비중으로 재계산합니다.
- 목표 비중이 같고 추가 입금이 없으면 가격 변동만으로 거래하지 않습니다.
- 추가 입금이 있으면 최신 잔고를 불러온 뒤 **추가 입금 반영 — 전체 계좌 재계산**을 선택합니다.
  입금액만 따로 배분하지 않으며, 기존 보유분과 입금 후 현금을 합한 전체 평가액을 사용합니다.
  10일 옵션 ON이면 보정 비중을 그대로 사용하며, 매수·매도가 함께 계산되어도 허용합니다.

현재 잔고 API만으로 입금과 가격 변동을 확정 구분할 수 없으므로 명시적 확인이 필요합니다.
이전의 '매수만 계산되면 입금으로 간주'하는 추정은 제거했습니다.
주문은 직접 실행하며, 체결 후 계좌를 새로 불러오면 확인 선택이 해제됩니다.
수동 입력도 잔고·현금이 바뀌면 확인 선택이 초기화됩니다.
입금이 없는 날에는 확인 항목을 선택하지 마세요.

추가 입금 확인은 실전 주문 계획에만 영향을 줍니다. 표시된 과거 고정자금 백테스트에
현재 입금액을 소급해서 넣지 않습니다. 추가 입금이 없어도 가격만으로 재매매하지 않는
과거 백테스트 원칙은 유지됩니다.

공통 알림 계산 함수도 같은 확인 인자를 사용합니다. 수동 알림 조회에는
`--cash-flow-rebalance soxx` 또는 `--cash-flow-rebalance qqq`를 각 계좌의 입금이
실제로 확인된 때만 사용합니다. 두 계좌 모두라면 옵션을 두 번 지정합니다.
기존 예약 실행에는 이 일회성 옵션을 추가하지 않았으며, 알림을 전송하거나 주문을 제출하지 않았습니다.
화면의 10일 옵션과 별도 알림의 전략 선택은 기존처럼 독립적입니다.
