# COMP Korea Stock Selection

성상현 『돈의 방향』의 COMP 설명을 바탕으로 만든 **연구용 수정 전략**입니다. 저자의 공식 구현이나 수익률 재현으로 보지 않습니다. 자동 주문이나 계좌 조회는 없습니다.

## 옵션

| 설정 | 선택 | 기본값 |
|---|---|---|
| 검증 기간 | 데이터 범위 내 시작일 / 종료일 | 데이터의 첫날 / 마지막 확정일 |
| 리밸런싱 | 4주 / 6주 | 6주 |
| 보유 수 | 10 / 15종목 | 10 |
| 밸류에이션 | 실적 PER 대체 / PER 제외 | 실적 PER |
| 성장률 | 전기 흑자만 / 전기 이익 절댓값 분모 | 전기 흑자만 |
| 섹터 선별 | 전체 / 직접 선택한 섹터 | 전체 |
| 섹터별 최대 보유 수 | 제한 없음 / 1~보유 수 | 제한 없음 |

섹터 선택과 보유 수 제한은 **서로 독립된 옵션**입니다. 섹터 옵션을 켜면 당시 알 수 있었던 분류가 필요합니다. 현재 분류를 과거에 소급하지 않으며 자료가 없거나 표본 분류가 불완전하면 실행을 중단합니다. 섹터 옵션은 새 확장이고 아래 검증 수익률을 적용할 수 없습니다. 선택 섹터 모드에서는 해당 섹터 표본을 먼저 고른 뒤 점수를 계산합니다. 섹터별 상한은 점수 계산 후 편입 시 적용합니다. 책의 ETF/펀더멘털/유동성 ‘세 눈’ 선별은 구현하지 않았습니다.

## 계산과 실행

화면에서 검증 가능한 기간을 표시합니다. 시작일은 데이터 첫날, 종료일은 마지막 확정일이 기본값이며 두 날짜 모두 그 범위 안에서 변경할 수 있습니다. 날짜 선택만으로 외부 데이터를 수집하지는 않습니다. 별도 코드에서 요청 종료일이 번들의 마지막 확정일보다 뒤이면 **실제 데이터까지만** 계산하고 요청일/실제 검증일을 따로 기록합니다. 없는 구간을 마지막 가격으로 늘리거나 오늘까지 검증했다고 표시하지 않습니다. 장중의 미확정 자료는 입력 생성 단계에서 제외해야 합니다. 로컬은 `latest.zip`이 있으면 우선 사용하고, 원격 앱에서 과거 ZIP을 올렸다면 최신 개인 ZIP으로 교체해야 합니다.

선택 시작일 이전 신호나 보유분을 이어받지 않고 새 자금으로 시작합니다. 첫 완료 주간 신호부터 4/6주 시계를 다시 셉니다. 종료일 이후 신호/가격은 사용하지 않습니다. 짧은 구간에 완료 주간 신호가 없으면 실행을 거부합니다.

- 점수: `100 * (N - rank) / N`. 좋은 값이 1위이며 동점은 평균 순위, 최상위 점수는 100 미만입니다.
- 순위 모멘텀: 20/60/125/252거래일 수익률 순위의 동일 비중 평균.
- 스마트머니: 20일 기관 순매수 금액, 외국인 순매수 금액, 외국인 보유 비율 **수준**의 순위 평균. 보유 비율 증가율이 아닙니다.
- 가격 모멘텀: 5/21/63일 수익률과 현재가/252일 최고 고가의 순위 평균.
- 밸류에이션: ROE, 영업이익 성장률, 낮은 PER 순위 평균. PER 제외 시 앞의 두 값만 평균.
- 최종: 순위 모멘텀 40%, 스마트머니 30%, 가격 모멘텀 20%, 밸류에이션 10%.
- ROE/실적 PER 입력은 같은 기준의 연결 우선 TTM 순이익과 평균 자기자본/당시 시가총액으로 계산한 값입니다. 영업이익 성장률은 전년 동일 누적기간 대비입니다.
- 기본 성장률은 `(당기 OP - 전기 OP) / 전기 OP`, 전기 OP가 양수일 때만 유효합니다. 대안은 분모를 `abs(전기 OP)`로 변경하고 0은 제외합니다. 대안은 저자의 확인된 공식이 아닙니다.
- PER 제외 비교도 동일한 양의 실적 PER 자료 충족 표본을 사용합니다. 적자기업 전체를 포함한 전략은 아닙니다.
- 신호는 완료된 주 마지막 거래일, 거래는 다음 시장 거래일 시가입니다. 80점 진입 제한과 65점 주간 자동 매도는 없습니다.
- 매수가 대비 종가 -20%를 감지한 다음 거래일 시가에 손절합니다. 갭 하락 시 실제 손실은 -20%보다 클 수 있습니다. 정기 교체 전까지 손절 대금은 현금입니다.
- 리밸런싱마다 전량 매도 후 실제 현금을 선택 종목에 균등 배분합니다. 유지 종목도 재매매하며 새로운 진입가로 손절 기준이 재설정됩니다.
- 편도 10bp 비용, 소수점 주식, 별도 배당 현금흐름 미포함. 유지 종목 차액만 거래하는 운용과는 비용이 다릅니다.

## 로컬/Streamlit 데이터

GitHub에는 코드만 저장합니다. 공급자 원자료, 인증키, 비밀번호, 개인 파일은 포함하지 않습니다. 화면은 `COMP_DATA_BUNDLE` 환경변수 또는 무시되는 로컬 `data/comp/research.zip`을 읽습니다. 원격 Streamlit에서는 개인 ZIP 업로드를 사용할 수 있습니다. 업로드는 사용자 세션에만 유지하며 별도 파일 추출이나 글로벌 캐시를 사용하지 않습니다. 서비스 운영자의 업로드/보안 정책은 별도로 확인해야 합니다.

기존 로컬 연구 결과에서 개인용 번들을 생성하려면:

```powershell
python scripts/export_comp_bundle.py --source "<local research period directory>" --output data/comp/research.zip
streamlit run main.py
```

이 번들에는 입력 지표/거래가격이 들어 있습니다. 공개 저장소에 업로드하지 마세요. 공급자 재배포 조건을 확인해야 합니다. `.gitignore`는 `data/`, CSV, ZIP, 로컬 테스트 환경을 제외합니다. 최근 데이터의 자동 수집 기능은 이 모듈에 포함하지 않았습니다. 기존 승인된 수집 경로에서 데이터를 갱신해 새로운 번들을 만들어야 합니다. 과거 번들의 마지막 신호는 오늘의 매매 신호가 아닙니다.

### 입력 계약

ZIP은 `metadata.json`, `features.csv`, `prices.csv`, `benchmarks.csv` 및 선택적 `sectors.csv`만 허용합니다. 100MB 압축/500MB 확장 한도입니다. 디스크로 압축을 풀지 않습니다.

- `metadata.json`: `schema_version=1`, `start`, `end`, 완결 주간 `signal_dates` 목록. 전략 시계는 표본이 없는 주도 이 목록을 따릅니다.
- `features.csv`: `date,ticker,name,filed,r5,r20,r21,r60,r63,r125,r252,near_high,institution,foreign,foreign_ratio,roe,per,op_previous,op_latest`. 수익률은 소수, OP는 같은 통화/회계기준, 순매수 금액은 동일 단위, 보유 비율은 0~100입니다. 기본 유니버스는 당시 시총 300억원 이상/20일 평균 거래대금 10억원 이상으로 **입력 생성 단계에서 필터**합니다. 새 공급원도 이 계약을 지켜야 합니다. 원자료에서 지표를 생성하는 전체 수집기는 이 모듈에 포함하지 않습니다.
- `prices.csv`: `date,ticker,open,close`. 동일 수정주가 기준, 양의 가격. 같은 날/종목 중복을 거부합니다.
- `benchmarks.csv`: `date,KOSPI,KOSDAQ`. 시작~종료 시장 거래일을 빠짐없이 포함합니다. 시작 지수는 첫 거래일 종가, 전략은 첫 주간 신호 이후 진입하므로 초기 노출이 다릅니다.
- `sectors.csv`: `ticker,sector,effective_date,known_date`. 효력일이 신호일 이전/당일이고 공지일이 신호일 **이전**인 분류만 사용합니다. 같은 날 알게 된 분류는 다음 신호부터 사용합니다. 섹터명 목록만 있는 현재 분류 파일은 받지 않습니다.

외부 입력의 수치/공지일이 실제 당시 정보인지 코드가 보증하지는 못합니다. 미래정보 사용 여부와 공급자 provenance를 별도로 검증해야 합니다.

## 검증 기록

2025-04-01~2026-03-31, 섹터 없음, 기본 성장률/실적 PER 대체 결과:

| 보유 수 | 주기 | 수익률 | 최대 낙폭 |
|---|---|---:|---:|
| 10 | 4주 | +108.08% | -18.57% |
| 10 | 6주 | +123.72% | -22.21% |
| 15 | 4주 | +68.75% | -16.07% |
| 15 | 6주 | +94.05% | -17.49% |
| 코스피 | 동일 기간 | +100.38% | -19.89% |
| 코스닥 | 동일 기간 | +52.20% | -17.97% |

16조건 탐색 결과는 +65.53~+128.71%였습니다. 일부 조건은 코스피보다 낮습니다. 책의 +179~189%는 재현되지 않았고, 정확한 책 거래일도 알려지지 않았습니다. 실적 PER 대체, 섹터 미적용, 17종목의 가격 이력 미반환, 신규상장/재무 자료 부족으로 주간 표본이 제한됩니다. 기본 표본은 평균 563.7종목, 대안은 625.4종목이며 두 성장률 방식의 결과 차이는 표본 변화도 포함합니다. 공시 정정 이력 및 상장폐지 누락의 생존 편향 때문에 완전한 point-in-time 검증은 아닙니다. 독립 기간 검증과 실제 주문 단위/거래 비용 검증이 필요합니다.
