# COMP 백테스트 계산 방법

성상현 작가의 『돈의 방향』을 바탕으로 만든 **연구용 수정 COMP**입니다. 저자의 공식 구현이 아닙니다. 아래는 현재 코드와 데이터 생성 과정에 실제로 적용한 계산법입니다.

## 1. 종목과 사용 가능한 정보

- 각 신호일 당시 KOSPI·KOSDAQ 주식 중 **시가총액 300억원 이상**, **최근 20거래일 평균 거래대금 10억원 이상**인 종목을 후보로 합니다. 이 조건은 데이터 파일 생성 단계에서 적용합니다.
- 가격·수급·외국인 보유 비율·재무 지표가 모두 유효한 종목만 점수 표본에 남깁니다. 252거래일 수익률에는 당일을 포함한 253개 종가가 필요합니다.
- 재무자료는 신호일 **이전에 공시된 자료**만 사용합니다. 같은 날 공시한 자료는 해당 신호에 쓰지 않습니다. 연결 재무제표를 우선하고, 비교 기간의 연결/별도 기준이 같아야 합니다.
- KRX 공식 일별 자료는 시가총액·거래대금, 키움 시장정보 자료는 가격·수급·보유 비율, DART는 재무자료에 사용했습니다. 시장 비교 지수는 네이버 일별 KOSPI·KOSDAQ 종가입니다.
- 입력 ZIP에는 미리 계산한 주간 지표와 일별 거래가격이 들어 있습니다. 날짜를 선택하는 것만으로 새 자료를 수집하지는 않습니다.

## 2. 서로 다른 지표를 점수로 변환

같은 신호일의 유효 표본 수를 `N`, 해당 지표에서 좋은 순서로 매긴 순위를 `rank`라고 합니다.

```text
S(x) = 100 × (N - rank(x)) / N
```

높을수록 좋은 지표는 내림차순, PER만 낮을수록 좋으므로 오름차순으로 순위를 매깁니다. 동점은 평균 순위입니다. 예를 들어 500종목 중 25위는 95점, 400위는 20점입니다. 1위는 99.8점으로, 최고점은 100점보다 작습니다.

책의 각주에 제시된 순위 식을 사용하며, 엑셀 `PERCENTRANK.INC`와 끝점 처리까지 같은 식은 아닙니다. 아래의 각 세부 지표를 먼저 `S()`로 변환한 뒤 평균냅니다. 네 기둥을 합친 후 다시 백분위 순위로 변환하지는 않습니다.

## 3. 네 기둥의 계산법

`t`는 신호일, `C_t`는 같은 수정주가 기준의 종가, `H_t`는 고가입니다. 기간의 숫자는 달력 날짜가 아니라 **시장 거래일 수**입니다.

### 순위 모멘텀: 최종 비중 40%

```text
r_n(t) = C_t / C_(t-n) - 1
순위 모멘텀 = [S(r_20) + S(r_60) + S(r_125) + S(r_252)] / 4
```

책의 4·12·25·52주를 20·60·125·252거래일로 구현했습니다. 서로 겹치지 않는 네 구간의 수익률이 아니라, **신호일에서 각각 과거로 거슬러 올라간 누적 수익률**입니다. 내부 네 기간은 동일 비중입니다.

### 스마트머니: 최종 비중 30%

```text
기관 순매수20 = 최근 20거래일의 (기관 매수금액 - 매도금액) 합계
외국인 순매수20 = 최근 20거래일의 (외국인 매수금액 - 매도금액) 합계
외국인 보유비율 = 신호일 외국인 보유주식수 / 상장주식수 × 100
스마트머니 = [S(기관 순매수20) + S(외국인 순매수20) + S(외국인 보유비율)] / 3
```

순매수는 금액 기준이며 음수도 그대로 순위를 매깁니다. 시가총액으로 나누지 않습니다. 외국인 보유 비율은 API의 비율 값을 사용합니다. 현재 구현은 **보유 비율의 수준**이지 증가율이나 변화량이 아니며, 별도의 추가 가중치도 없습니다.

### 가격 모멘텀: 최종 비중 20%

```text
신고가 근접도 = C_t / max(H_(t-251), ..., H_t)
가격 모멘텀 = [S(r_5) + S(r_21) + S(r_63) + S(신고가 근접도)] / 4
```

1주·1개월·3개월은 5·21·63거래일로 구현했습니다. 신호일을 포함한 최근 252거래일의 **장중 최고 고가**에 가까울수록 높은 점수를 줍니다. 하락 괴리율을 사용한다면 `1 - 신고가 근접도`이므로 작을수록 좋은 값이 됩니다.

### 밸류에이션: 최종 비중 10%

```text
분기/반기의 TTM 순이익 = 전년도 연간 순이익 + 당해 누적 순이익 - 전년 동일 누적 순이익
연간 보고서의 TTM 순이익 = 해당 연간 순이익
평균 자기자본 = (최신 보고기간 말 자기자본 + 전년 동일 보고기간 말 자기자본) / 2
ROE = TTM 순이익 / 평균 자기자본
실적 PER = 신호일 시가총액 / TTM 순이익

영업이익 성장률 = (당해 누적 영업이익 - 전년 동일 누적 영업이익) / 전년 동일 누적 영업이익
밸류에이션 = [S(ROE) + S(영업이익 성장률) + S(실적 PER: 낮을수록 좋음)] / 3
```

ROE는 평균 자기자본이 양수일 때만, PER는 TTM 순이익이 양수일 때만 계산합니다. 영업이익 성장률은 **TTM 성장률이 아니라 전년 동일 누적기간 대비**이며, 연간 자료는 연간끼리 비교합니다.

- **전기 흑자만:** 전년 동일기간 영업이익이 양수인 경우만 성장률을 계산합니다.
- **전기 손실 허용:** 성장률 분모를 전년 영업이익의 절댓값으로 바꿉니다. 전년 영업이익이 0인 종목은 제외합니다. 이는 별도로 정한 대안입니다.
- **PER 제외:** ROE와 영업이익 성장률 두 점수만 평균냅니다. 다른 기둥의 가중치는 그대로입니다. 비교 표본을 맞추기 위해 이 옵션에서도 양의 실적 PER 자료를 갖춘 종목만 사용합니다.

책의 **선행 PER 대신 실적 PER를 사용**합니다. 과거 당시의 이익 전망치를 확보하지 못했기 때문에 원래 밸류에이션과 동일하지 않습니다.

### 최종 COMP 점수

```text
COMP = 0.40 × 순위 모멘텀
     + 0.30 × 스마트머니
     + 0.20 × 가격 모멘텀
     + 0.10 × 밸류에이션
```

## 4. 신호, 종목 선정과 리밸런싱

1. **완료된 주의 마지막 시장 거래일** 종가를 기준으로 점수를 계산합니다. 매주 점검하지만 정기 거래는 선택한 4주 또는 6주 간격입니다.
2. 선택 기간의 첫 완료 주간 신호를 시작점으로, 신호 목록에서 4주라면 1·5·9번째, 6주라면 1·7·13번째 신호를 정기 교체 신호로 사용합니다.
3. COMP 점수가 높은 순서로 10종목 또는 15종목을 선정합니다. 80점 이상 진입 조건과 65점 미만 주간 자동 매도 조건은 현재 적용하지 않습니다.
4. 신호일에는 거래하지 않고 **다음 시장 거래일 시가**에 기존 보유 종목을 전량 매도한 뒤, 실제 남은 현금을 선정 종목에 동일 금액으로 배분합니다. 기존에 보유하던 선정 종목도 매도 후 다시 매수합니다.
5. 새로운 매수가로 손절 기준을 다시 설정합니다. 소수점 주식 매수를 허용하며, 다음 정기 교체 전에는 가격 변동에 따른 비중 차이를 매일 맞추지 않습니다.

시작일을 바꾸면 기존 보유분을 이어받지 않고 초기 자금부터 새로 시작하며, 리밸런싱 일정도 다시 셉니다. 시작일 이후 첫 완료 주간 신호의 다음 거래일까지 전략은 현금입니다. 종료일에는 종가로 평가하며 보유분을 강제로 청산하지 않습니다.

섹터 선택을 켜면 선택한 섹터 표본 안에서 순위를 다시 계산합니다. 섹터별 보유 수 제한은 점수 계산 후 선정 단계에서 적용하며, 두 옵션은 독립적입니다. 과거 효력일·공지일이 있는 분류가 필요하고, 없거나 불완전하면 실행하지 않습니다. 책의 ETF 기반 ‘세 눈’ 섹터 선별은 구현하지 않았습니다.

## 5. 거래 비용, 손절과 현금

`f = 편도 비용(bp) / 10,000`입니다. 기본값 10bp는 매수·매도 각각 0.1%입니다. 매도 후 현금을 `B`, 선정 수를 `m`, 해당 종목의 다음 시가를 `P`라고 하면:

```text
종목별 비용 포함 배정금액 = B / m
매수 수량 = (B / m) / [P × (1 + f)]
매수 시 현금 차감 = 수량 × P × (1 + f)
매도 시 현금 증가 = 수량 × 매도 시가 × (1 - f)
```

```text
손절 조건: 당일 종가 / 해당 보유분의 매수 시가 - 1 ≤ -20%
손절 실행: 조건 확인 다음 시장 거래일 시가에 매도
```

종가 확인 후 매도하므로 -20%에 체결되는 보장이 없으며, 갭 하락 시 손실은 더 커질 수 있습니다. 손절 대금은 다음 정기 리밸런싱까지 현금으로 둡니다. 현금 이자는 없고, 배당금의 별도 현금 유입도 반영하지 않습니다. 세금·슬리피지를 따로 정밀 모델링하지 않고 설정한 편도 비용으로 비용을 가정합니다.

매수일 가격이 없으면 해당 매수는 건너뛰고 그 금액을 현금으로 남깁니다. 보유 중 가격이 누락되면 마지막 확인 가격으로 평가하고 누락 보유일을 기록합니다. 매도 예정 종목에 시가가 없으면 유효 가격이 나오는 날까지 매도를 미룹니다. 이러한 누락은 성과 해석의 한계입니다.

## 6. 수익률과 최대 낙폭(MDD)

```text
전략 자산 V_t = 현금_t + Σ(보유 수량 × 당일 종가)
누적 수익률 = V_마지막 / V_첫날 - 1
시장 비교 자산 I_t = 초기 자금 × 지수 종가_t / 선택 기간 첫 거래일 지수 종가
일별 낙폭 D_t = V_t / max(V_첫날, ..., V_t) - 1
MDD = min(D_t)
```

KOSPI·KOSDAQ도 **각 지수 자신의 누적 최고점**을 기준으로 낙폭과 MDD를 계산합니다. 그래프는 `D_t × 100`의 % 단위이며, MDD는 일별 종가 기준의 가장 큰 하락폭입니다. 장중 최대 낙폭은 아닙니다. 지수는 첫 거래일부터 노출되지만 전략은 첫 주간 신호 이후 진입하므로 초기 노출에 차이가 있습니다.

## 7. 책과 다른 가정 및 검증의 한계

책에 명시된 최종 가중치와 순위 점수 식을 사용했습니다. **세부 지표 동일 비중, 거래일 환산, 외국인 보유 비율 수준 사용, 실적 PER 대체, 성장률 대안, 정기 전량 재매매** 등은 이번 구현의 규칙입니다. 이를 저자의 정확한 구현으로 보지 않습니다.

상장폐지 종목의 가격 미제공, 신규상장 이력 부족, 재무자료 부족으로 표본이 제한됩니다. 신호 이후 공시는 제외하지만 현재 API의 과거 재무자료에 정정된 값이 포함될 수 있어, 당시 원본을 완전히 복원한 검증은 아닙니다. 생존 편향과 정정 공시 편향이 남아 있습니다. 과거 자료로 계산한 결과는 미래 수익을 보장하지 않으며, 자동 주문은 실행하지 않습니다.
