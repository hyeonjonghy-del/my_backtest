# 삼성전자 추세·변동성 전략 v2

KODEX 200 Bull/Bear 전략의 장기 추세·실현변동성 필터를 삼성전자 보통주(005930)에 맞게 변형한 현금 혼합 전략입니다.

## 기본 규칙

- 삼성전자 종가가 120일 이동평균 아래이면 현금으로 대기합니다.
- 추세가 상승이고 60거래일 모멘텀이 양수이며 RV20이 65% 이하이면 목표 변동성 30%에 맞춰 삼성전자 비중을 65~100%로 조절합니다.
- 상승 추세지만 모멘텀이 음수이면 삼성전자 비중을 최대 35%로 낮춥니다.
- 상승 추세지만 RV20이 65%를 초과하면 전량 매도하지 않고 삼성전자 35%를 보유합니다.
- 투자하지 않은 비중은 현금으로 둡니다. 현금 이자는 보수적으로 0%로 가정합니다.
- 당일 종가 신호는 다음 거래일 시가에 체결하며, 기본 거래비용은 편도 0.15%입니다.
- 장기 이력의 액면분할 왜곡을 줄이기 위해 조정주가를 우선 사용하고 기본 시작일은 2019년으로 둡니다.

## 주의사항

이 전략은 과거 가격만 사용하는 연구용 백테스트입니다. 배당, 세금, 호가 공백, 시장충격과 현금 이자는 반영하지 않으며 미래 성과를 보장하지 않습니다. 단일 종목은 지수 ETF보다 기업 고유 위험이 크므로 전체 자산이 아니라 별도 한도 안에서 운용하는 편이 안전합니다.

v2에서는 RV20과 모멘텀을 전량 매도 조건이 아니라 비중 축소 조건으로 사용합니다. 백테스트 화면의 손익 감사표에서 야간 갭, 장중 수익률, 거래비용을 분리해 확인할 수 있습니다.
